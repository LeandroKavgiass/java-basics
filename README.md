# Java Fundamentals

Repositório com exercícios desenvolvidos durante meus estudos de Java, com foco na prática da lógica de programação e dos conceitos fundamentais da linguagem.

## 🚀 Tecnologias

- Java

## 📚 Exercícios desenvolvidos

- Soma de dois números
- Cálculo de média simples
- Conversão de idade para dias
- Conversão de temperatura
- Conversão de moeda
- Cálculo do salário
- Cálculo da área de um círculo
- Cálculo do perímetro e área de um retângulo
- Cálculo do volume de uma esfera
- Distância entre dois pontos

## 🎯 Objetivos

- Praticar a sintaxe da linguagem Java
- Desenvolver a lógica de programação
- Resolver problemas utilizando algoritmos
- Aplicar conceitos matemáticos em programação
- Criar uma base sólida para projetos mais avançados em Java
